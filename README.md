# CareerPath – AI Career Mentor Portal

**Course:** CSE326 – Internet Programming  
**Academic Task:** CA1 Project  
**Project type:** Responsive front-end web application

## About the project
CareerPath is a student career-planning portal. A student can enter their interests and current skills, view a starter career direction, search career cards, and track learning tasks.

> Project scope note: this version uses rule-based JavaScript examples and browser storage. It does not connect to a real AI model, live job database, or certification provider. Describe it as a working front-end prototype during the demonstration.

## Files
- `index.html` – page structure and form
- `style.css` – layout, colours, responsive design
- `script.js` – validation, DOM updates, search, dialog and local storage

## Run locally
1. Download and extract the project ZIP.
2. Open the `ai-career-mentor-portal` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

No build tools or package installation are required.

## Features demonstrated
- Semantic HTML sections, navigation, form, labels and buttons
- Responsive CSS using grid, flexbox and media queries
- JavaScript form validation and event handling
- DOM manipulation for dashboard values and career details
- Career search using the input event
- `localStorage` to save the profile and roadmap progress
- HTML dialog element for career detail popups
- Basic console logging for debugging

## GitHub Pages deployment
1. Create a GitHub repository, for example `careerpath-cse326`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Open the URL shown in the Pages section.
